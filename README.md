Bits and pieces from the comms shack. Mostly here so I stop losing them every time a laptop dies.

- `netcheck.sh` pings the usual suspects and tells you which one fell over
- `freqlog.py` turns my scribbled freq log into a csv
- `motd.txt` not a script. leave it alone

No support. If it breaks you get to keep both halves.
